# Repi — legal pages

Публичные страницы приложения **Repi: Learn and repeat** (iOS).
Публикуются через GitHub Pages, ссылка указывается в App Store Connect.

- `index.html` — Privacy Policy (English)
- `ru.html` — Политика конфиденциальности (русский)

Исходные тексты живут в приложении (`src/i18n/*.json`, раздел `privacy`)
и внутри него же показываются на экране Настройки → Политика конфиденциальности.
Правки вносятся там, эти страницы пересобираются из них.
