Smarty Smart Uploader

Privacy Policy

Updated 21 October 2026

Smarty Smart Uploader is a private tool that uploads videos to the owner's own YouTube channels (Smarty Smart and STEREO OWL). It is used only by the channel owner and does not serve other users.

YouTube API Services

The tool uses YouTube API Services. Its use is subject to the YouTube Terms of Service and the Google Privacy Policy.

What data the tool accesses

With the owner's permission, the tool requests access to the owner's YouTube account through Google OAuth (scopes for uploading and managing the owner's videos). It uses this access only to upload videos, set their titles, descriptions, tags and thumbnails, schedule publishing, and read the basic details of the owner's channel and uploads to confirm that an upload succeeded.

How data is stored

The OAuth tokens are stored only on the owner's computer, in the tool's local configuration folder. The tool has no server and no database, and it does not send YouTube account data anywhere other than Google's own APIs.

What we do not do

We do not collect, sell or share any user data, we do not use it for advertising, and we do not access data of any other YouTube users. The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time on the Google security settings page: myaccount.google.com/permissions. Deleting the local token files removes all stored credentials.

Changes

If this policy changes, the updated version will be published on this page with a new date.
